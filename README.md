# BaristaVoice
A speech-to-order coffee ordering system for coffee shops, allowing efficient order and inventory tracking. It takes speech and converts it into real orders, which are added ro an order queue and can then be ticked off. Inventory levels are also updated live with each order.
Built with **HTML, Javascript, and CSS**
Deployed using **netlify**
Link to try: http://incomparable-flan-380d77.netlify.app
